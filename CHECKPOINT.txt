МАСТЕР-ЧЕКПОИНТ ПРОЕКТА BOXING COACH

Этот документ — полное руководство по архитектуре проекта. Он создан для того, чтобы любой новый чат с ИИ мгновенно понял, как устроен код, и мог безопасно вносить изменения.

1. ОБЩАЯ ИНФОРМАЦИЯ
Стек: Vanilla JavaScript (без фреймворков), HTML, CSS, Supabase (база данных и авторизация), Chart.js (графики), jsPDF (экспорт PDF).
Архитектура: Модульная. Код разбит на 20+ маленьких файлов (модулей), каждый отвечает за свою задачу.
Хранение данных: Supabase (облако) + LocalStorage (офлайн-режим и кэш).
Версия Service Worker: boxcoach-v9 (обновлена, календарь в стиле iOS).
Публикация: GitHub Pages (renatsherman.github.io/boxing-coach).

2. СТРОГИЕ ПРАВИЛА РАБОТЫ С ЧАТОМ (ВАЖНО ДЛЯ ИИ!)
- Пользователь не умеет работать с кодом и не использует VS Code. Все изменения делаются только через веб-интерфейс GitHub.
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО давать куски кода, писать "замени строчку" или "добавь функцию". Любой измененный модуль должен выдаваться ПОЛНОСТЬЮ от начала и до конца, готовым к полной замене файла.
- Если меняется несколько файлов, они должны быть пронумерованы: "Файл 1: ...", "Файл 2: ..." и т.д.
- Если меняются любые файлы, ОБЯЗАТЕЛЬНО нужно выдавать обновленный sw.js с новой версией кэша (v10, v11 и т.д.).
- После каждой правки ИИ ОБЯЗАН выдавать обновленный МАСТЕР-ЧЕКПОИНТ, чтобы история изменений сохранялась для следующих чатов.

4. ПОДРОБНОЕ ОПИСАНИЕ МОДУЛЕЙ

ФУНДАМЕНТ (Ядро приложения)
config.js: Только константы. Ключи Supabase, максимальный балл (MAX_SCORE = 10), дефолтные группы, упражнения, направления. Пустая база данных (defaultDB).
utils.js: Вспомогательные функции. Расчет возраста, форматирование дат, средние баллы (avgAll), работа с группами (groupName), уведомления (toast). Важно: здесь функция emptyAssess (создание пустой матрицы оценок).
data.js: Ядро базы данных (DB). Загрузка из LocalStorage (loadLocal), миграции (если структура базы изменилась), сохранение локально (saveLocal). Переменная DB объявлена через var (а не let), чтобы избежать ошибок при инициализации.
cloud.js: Работа с Supabase. Авторизация (вход/регистрация), функция saveData (сохраняет локально и отправляет в облако), слушатели интернета (online/offline) и отложенная синхронизация.
attendance-data.js: Логика посещаемости. Группировка тренировок по сессиям, проверка статуса (был/не был), добавление внеплановых бойцов (гостей).
journal.js: Рекомендации. Анализ оценок бойца (поиск слабых сторон) и подбор упражнений (по ключевым словам).

НАВИГАЦИЯ И РОУТИНГ
nav.js: Глобальные переменные app (главный див) и state (текущая вкладка). Объект Modal (управление всплывающими окнами). Экран входа (LockScreen). Главный роутер (функция render()), которая переключает экраны.

ЛОГИКА БОЙЦОВ
fighters-core.js: Создание нового бойца, загрузка и сжатие фото (до 300x300), базовые поля (имя, вес), а также модалка назначения тренировок.
assessments.js: Оценки по направлениям. Модалки добавления/редактирования, сохранение баллов, отрисовка радара (паутины) Chart.js.
measurements.js: Замеры (отжимания, пресс). Добавление, удаление и отрисовка линейных графиков Chart.js.
fighter-detail.js: Экран карточки бойца. Собирает воедино оценки, замеры, бои, план работы и встраивает календарь. Здесь же карточка посещаемости и слабых сторон.

ФУНКЦИОНАЛ
calendar.js: Два календаря. 1) Месячный для бойца. 2) Недельный для тренера (сетка со свободными часами). Календарь тренера стилизован под iOS (темная тема, свайп дней, фиксированная высота, красная линия текущего времени).
attendance.js: Интерфейс отметки. Чек-листы для групп, кнопки "Отметить всех", отправка текста в мессенджеры (копирование/Web Share).
reports.js: Отчеты за месяц. Считает количество тренировок, посещаемость, рисует графики, собирает данные для PDF.
exercises.js: Справочник. Вкладки управления блоками упражнений и замерами.
pdf.js: Экспорт. Генерация PDF через jsPDF (шрифты, таблицы, графики).

ИНТЕРФЕЙС (Экраны)
dashboard.js: Главный экран. Карточки групп, Календарь тренера, Аккордеоны (сворачиваемые списки) с последними тренировками и теми, кто давно не был. Топ-3 бойца. График сезона.
compare.js: Сравнение двух бойцов. Таблица с разницей баллов и наложение двух радаров.
settings.js: Настройки. Имя тренера, управление группами (создание, переименование, удаление), управление направлениями и критериями оценок, экспорт/импорт JSON.

ТОЧКА ВХОДА
app.js: Самый короткий файл. Функции экспорта/импорта всей базы JSON, инициализация (LockScreen.init, Cloud.init) и регистрация Service Worker.

5. ТЕХНИЧЕСКИЕ ПРАВИЛА И ПОДВОДНЫЕ КАМНИ

Функции для onclick: Все функции, которые вызываются из HTML-атрибутов (например, onclick="openFighter()"), должны быть объявлены через window.openFighter = () => {} или быть глобальными function openFighter(). Иначе браузер их не найдет.
var DB вместо let DB: В data.js база объявлена через var. Это сделано специально. Функция emptyAssess из utils.js загружается раньше и проверяет typeof DB. Если бы DB была через let, браузер выдал бы критическую ошибку.
Service Worker (sw.js): При ЛЮБОМ изменении файлов в проекте нужно менять версию кэша: const CACHE_NAME = 'boxcoach-v9'; на v10, v11 и т.д. Иначе изменения не подтянутся.
Сброс кэша: После обновления файлов всегда делай Ctrl + F5 на компьютере. На телефоне может потребоваться полностью закрыть вкладку и открыть заново.
