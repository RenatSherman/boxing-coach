МАСТЕР-ЧЕКПОИНТ ПРОЕКТА BOXING COACH

Этот документ — полное руководство по архитектуре проекта. Он создан для того, чтобы любой новый чат с ИИ мгновенно понял, как устроен код, и мог безопасно вносить изменения.

1. ОБЩАЯ ИНФОРМАЦИЯ
Стек: Vanilla JavaScript, HTML, CSS, Supabase, Chart.js, jsPDF.
Архитектура: Модульная (20+ файлов). Адаптивная верстка (меню на ПК сверху, на телефоне снизу).
Хранение данных: Supabase (облако) + LocalStorage (офлайн-режим и кэш).
Версия Service Worker: boxcoach-v28.
Публикация: GitHub Pages.

2. СТРОГИЕ ПРАВИЛА РАБОТЫ С ЧАТОМ (ВАЖНО ДЛЯ ИИ!)
- Пользователь не умеет работать с кодом и не использует VS Code. Все изменения делаются только через веб-интерфейс GitHub.
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО давать куски кода. Любой измененный модуль должен выдаваться ПОЛНОСТЬЮ, готовым к полной замене файла.
- Если меняется несколько файлов, они должны быть пронумерованы: "Файл 1: ...", "Файл 2: ..." и т.д.
- Если меняются любые файлы, ОБЯЗАТЕЛЬНО нужно выдавать обновленный sw.js с новой версией кэша (v29, v30 и т.д.).
- После каждой правки ИИ ОБЯЗАН выдавать обновленный МАСТЕР-ЧЕКПОИНТ (этот текст).

4. ПОДРОБНОЕ ОПИСАНИЕ МОДУЛЕЙ

ФУНДАМЕНТ (Ядро приложения)
config.js: Константы.
utils.js: Вспомогательные функции (даты по локальному времени телефона).
data.js: Ядро БД. Переменная DB через var.
cloud.js: Синхронизация с Supabase.
attendance-data.js: Логика посещаемости. Здесь добавлен статус 'cancelled'.
journal.js: Рекомендации.

НАВИГАЦИЯ И РОУТИНГ
nav.js: Глобальные переменные app и state. Модалки. Экран входа. Роутер render(). При клике на "Отметка" вызывает Attendance.setToday() до вызова render().

ЛОГИКА БОЙЦОВ
fighters-core.js: Создание бойца, фото, модалка тренировок (с кнопками быстрого выбора групп).
assessments.js: Оценки (радар).
measurements.js: Замеры (графики).
fighter-detail.js: Экран карточки бойца. Список бойцов в виде аккордеонов групп. Оценки и замеры в виде карточек.

ФУНКЦИОНАЛ
calendar.js: Календарь бойца (месяц) и тренера (iOS стиль).
attendance.js: Отметка. Тренировки в аккордеонах. При заходе всегда открывается текущий день. Для индивидуальных тренировок есть кнопки "Проведена" и "Не проведена".
reports.js: Отчеты (карточки).
exercises.js: Справочник.
pdf.js: Генерация PDF.

ИНТЕРФЕЙС (Экраны)
index.html: Шапка, меню.
dashboard.js: Главный экран. Календарь тренера, аккордеоны. Свайпы.
compare.js: Сравнение.
settings.js: Настройки.

ТОЧКА ВХОДА
app.js: Инициализация. Ждет DOMContentLoaded.

5. ТЕХНИЧЕСКИЕ ПРАВИЛА И ПОДВОДНЫЕ КАМНИ
- При изменении файлов ОБЯЗАТЕЛЬНО менять версию кэша в sw.js.
- Сброс кэша: Ctrl + F5 на ПК. На iPhone — очистка данных Safari.
- todayStr() в utils.js использует локальное время устройства.
