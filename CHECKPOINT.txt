МАСТЕР-ЧЕКПОИНТ ПРОЕКТА BOXING COACH

Этот документ — полное руководство по архитектуре проекта. Он создан для того, чтобы любой новый чат с ИИ мгновенно понял, как устроен код, и мог безопасно вносить изменения.

1. ОБЩАЯ ИНФОРМАЦИЯ
Стек: Vanilla JavaScript, HTML, CSS, Supabase (авторизация, БД), Chart.js (графики), jsPDF (экспорт PDF).
Архитектура: Модульная (20+ файлов). Адаптивная верстка (разделение на мобильный и ПК вид).
Хранение данных: Supabase (облако) + LocalStorage.
Версия Service Worker: boxcoach-v15.
Публикация: GitHub Pages (renatsherman.github.io/boxing-coach).

2. СТРОГИЕ ПРАВИЛА РАБОТЫ С ЧАТОМ (ВАЖНО ДЛЯ ИИ!)
- Пользователь не умеет работать с кодом и не использует VS Code. Все изменения делаются только через веб-интерфейс GitHub.
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО давать куски кода. Любой измененный модуль должен выдаваться ПОЛНОСТЬЮ от начала и до конца, готовым к полной замене файла.
- Если меняется несколько файлов, они должны быть пронумерованы: "Файл 1: ...", "Файл 2: ..." и т.д.
- Если меняются любые файлы, ОБЯЗАТЕЛЬНО нужно выдавать обновленный sw.js с новой версией кэша (v16, v17 и т.д.).
- После каждой правки ИИ ОБЯЗАН выдавать обновленный МАСТЕР-ЧЕКПОИНТ (этот текст).

4. ПОДРОБНОЕ ОПИСАНИЕ МОДУЛЕЙ

ФУНДАМЕНТ
config.js: Константы. Ключи Supabase, MAX_SCORE, группы, defaultDB.
utils.js: Вспомогательные функции (возраст, даты, группы, toast, emptyAssess).
data.js: Ядро базы данных (DB), loadLocal, миграции, saveLocal. Переменная DB через var.
cloud.js: Работа с Supabase. Авторизация, saveData, слушатели online/offline.
attendance-data.js: Логика посещаемости. Группировка, статусы, внеплановые.
journal.js: Рекомендации (слабые стороны, подбор упражнений).

НАВИГАЦИЯ И РОУТИНГ
nav.js: Глобальные переменные app и state. Объект Modal. Экран входа (LockScreen). Главный роутер render(). Ждет DOMContentLoaded.

ЛОГИКА БОЙЦОВ
fighters-core.js: Создание бойца, сжатие фото, модалка тренировок.
assessments.js: Оценки (модалки, радар).
measurements.js: Замеры (добавление, линейные графики).
fighter-detail.js: Экран карточки бойца (собирает все блоки).

ФУНКЦИОНАЛ
calendar.js: Календарь бойца (месяц) и Календарь тренера (iOS стиль, свайпы дней, темная тема).
attendance.js: Отметка (крупные чекбоксы для мобильных).
reports.js: Отчеты (карточки бойцов вместо таблицы для мобильных).
exercises.js: Справочник (упражнения и замеры).
pdf.js: Генерация PDF.

ИНТЕРФЕЙС (Экраны)
index.html: Адаптивная шапка, меню навигации (на ПК сверху, на телефоне снизу).
dashboard.js: Главный экран. Календарь сразу под шапкой. Аккордеоны. Свайпы.
compare.js: Сравнение бойцов.
settings.js: Настройки.

ТОЧКА ВХОДА
app.js: Экспорт/импорт JSON, инициализация (LockScreen.init, Cloud.init) и регистрация SW. Ждет DOMContentLoaded.

5. ТЕХНИЧЕСКИЕ ПРАВИЛА И ПОДВОДНЫЕ КАМНИ
- Функции для onclick через window.
- var DB вместо let DB.
- При изменении файлов ОБЯЗАТЕЛЬНО менять версию кэша в sw.js.
- Сброс кэша: Ctrl + F5 на ПК. На iPhone — очистка данных Safari.
- АДАПТИВНОСТЬ: В style.css есть медиа-запрос @media (min-width: 768px), который перестраивает меню с нижнего на верхнее для ПК.
